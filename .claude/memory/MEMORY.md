## 使用说明

### 记忆更新时机

每次 session 结束时，Claude Code 会自动更新相关记忆文件：

1. **发现新的架构洞察** → 更新对应记忆文件
2. **修复重要 Bug** → 追加到 `bugs-fixed.md`
3. **性能优化** → 记录到 `performance.md`
4. **第三方集成经验** → 记录到对应文件

### 记忆读取时机

每次 session 开始时，读取相关记忆以避免重复错误：

1. **遇到 Supabase 问题** → 读取 `supabase.md`
2. **窗口管理问题** → 读取 `window-system.md`
3. **性能问题** → 读取 `performance.md`
4. **已知 Bug** → 读取 `bugs-fixed.md`

## 维护指南

### 添加新记忆

1. 创建新的 `.md` 文件
2. 使用模板填写内容
3. 在本文件中添加链接
4. 更新"当前记忆状态"

### 更新现有记忆

1. 找到对应的 `.md` 文件
2. 追加新内容（不要删除旧内容）
3. 更新"最后更新"日期
4. 更新本文件的"当前记忆状态"

### 记忆归档

当记忆文件过大（超过 1000 行）时：
1. 创建归档文件 `{name}-archive-YYYY.md`
2. 移动旧内容到归档文件
3. 保留最近 6 个月的记忆
