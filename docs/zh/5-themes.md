# 主题

三套主题。三个年代。

## macOS Aqua

2001 年。Steve Jobs 说："我们做了一个你想舔的界面。"

透明、圆角、果冻按钮。这是默认主题。

## Windows XP

2001 年。蓝天白云绿草地。一亿人的桌面记忆。

Luna 蓝配色、圆角窗口、经典的开始按钮。

## Windows 98

1998 年。灰色、直角、像素字体。

没有圆角，没有阴影，没有废话。界面最诚实的年代。

## 实现方式

所有颜色都是 CSS 变量。没有硬编码。

```css
var(--window-bg)
var(--window-border)
var(--titlebar-bg)
```

切换主题就是切换一组变量。组件不需要知道当前是什么主题。

壁纸系统独立于主题。你可以用 Aqua 的窗口配 XP 的草地。规则由你定。
