# 快速开始

打开 [kyo.is](https://kyo.is)。没有注册，没有登录，没有引导流程。

你的数据存在浏览器里。不经过任何服务器。

## 放一个链接

按 `Cmd+K` 打开命令面板，或者直接把链接粘贴到桌面。

Kyo 会自动抓取标题和图标。你也可以自己改。

## 写一张便签

双击桌面空白处，或者从 Dock 打开便签应用。

写下你此刻在想的事情。不需要标题，不需要分类。

## 没有第三步

用就行了。

## 快捷键

- `Cmd+K` — 命令面板，唯一的入口
- `Cmd+V` — 粘贴创建，链接变书签，文字变便签
- `Cmd+,` — 设置

## 数据

一切存在本地。你可以在设置中导出备份，也可以从备份恢复。

如果你清除浏览器数据，一切都会消失。这是设计决定，不是缺陷。你的数据只属于你。
