# Kyo

Kyo 是一面镜子。

鏡（きょう），日语中"镜"的读音。你的数字空间应该映射你自己，而不是这个世界的噪音。

每一个现代工具——Notion、Figma、ChatGPT——本质上都只是一个链接。你不需要下载任何东西。你只需要一个地方来安放它们。

Kyo 把你的链接变成一个桌面。你的收藏夹，就是你的操作系统。

## 三层空间

**表层** — 你看到的。壁纸、Dock、快捷方式。这是你的桌面。

**门户** — 你触发的。按下 `Cmd+K`，一切唾手可得。这是你的命令中心。

**深处** — 你沉浸的。对话、笔记、白噪音。这是你的私人空间。

## 不是什么

Kyo 不是收藏夹管理器。Cubox 是仓库——你把东西扔进去，然后检索。

Kyo 不是新标签页。iTab 展示世界给你看——热搜、新闻、天气。

Kyo 是一个房间。你住在里面。桌子上只放你选择放的东西。

> Cubox 问你：那个链接存哪了？
> iTab 问你：今天发生了什么？
> Kyo 问你：你的桌面上想放什么？
