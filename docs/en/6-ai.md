# AI

Kyo's AI is not a chatbot. It's part of your desktop.

## Context Awareness

It knows your bookmarks. It knows your notes.

When you say "find that design tool," it doesn't search the web — it searches your collection.

## Local Intent

Not every conversation needs to hit the cloud.

- Search bookmarks → handled locally
- Find notes → handled locally
- Everything else → cloud API

## Design Principle

AI should be invisible. You shouldn't need to learn prompt engineering to use it well.

Just ask.
