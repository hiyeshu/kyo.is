# Kyo.is 开发路线

## 当前阶段：记忆与 Agent 能力

### 核心目标

构建 KYO 的**自我进化能力**，让 AI Agent 能够：
- 记住过去的决策和经验
- 理解项目的完整上下文
- 快速定位和执行任务
- 积累知识并传递给下一个 session
